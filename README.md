# ✨ Premium Calculator

A stunning, modern calculator built with vanilla HTML, CSS, and JavaScript — featuring glassmorphism design, smooth animations, and both **Standard** and **Scientific** modes.

## 🚀 Features

### 🧮 Standard Mode
- Addition, Subtraction, Multiplication, Division
- Percentage & Sign Toggle (±)
- Decimal support

### 🔬 Scientific Mode
- **Trigonometry** — sin, cos, tan (degree-based)
- **Logarithms** — log (base 10), ln (natural)
- **Power & Roots** — x², √
- **Constants** — π, e
- **Factorial** — n!

### 🎨 Design
- 🌌 **Glassmorphism UI** with frosted glass effects
- 🔮 **Animated gradient orbs** floating in the background
- 💫 **Ripple effects** on every button click
- ✨ **Micro-animations** — result pop, error shake, smooth transitions
- 🎯 **Operator highlighting** to show active operation

### ⚡ Other
- ⌨️ **Full keyboard support** — type numbers, operators, Enter, Escape, Backspace
- 🕐 **Calculation history** — view and reuse past calculations
- 📱 **Responsive design** — works on desktop and mobile
- 🚫 **No dependencies** — pure HTML, CSS & JavaScript

## 🛠️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/niteshyadav07-hub/Calculator.git
   ```

2. **Open in browser**
   ```bash
   cd Calculator
   open index.html
   ```
   Or simply double-click `index.html` — no server required!

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Input numbers |
| `+` `-` `*` `/` | Operations |
| `.` | Decimal point |
| `Enter` or `=` | Calculate result |
| `Escape` or `Delete` | Clear all |
| `Backspace` | Delete last digit |
| `%` | Percentage |
